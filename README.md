# NetAssist Starter

A Java 17 Swing application that performs basic network troubleshooting checks:

- Local IPv4 interface discovery
- DNS resolution
- Host reachability
- TCP port connectivity
- Plain-language diagnostic summary

## Run in Eclipse

1. Import the folder as an **Existing Maven Project**.
2. Confirm the project uses **Java 17**.
3. Run `com.yousef.netassist.Main` as a Java application.

## Safe use

Run checks only against systems and networks you own or are authorized to test.
